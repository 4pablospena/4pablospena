## Del problema al producto

Construyo productos digitales a partir de problemas de usuario. Trabajo con TypeScript, React y Vue, y desarrollo herramientas para configurar agentes de IA, supervisar su actividad y controlar sus acciones.

Me interesa cómo encajan los agentes en un producto: qué pueden hacer, qué límites necesitan y cómo interviene la persona que los utiliza.

## Proyecto actual · Siarem

<a href="https://github.com/4pablospena/siarem"><img src="./assets/projects/siarem.svg" alt="Siarem — Mi proyecto actual. CRM de ventas y entrega." width="100%" /></a>

Estoy desarrollando **Siarem**, un CRM en español para gestionar ventas y entrega en equipo. Reúne empresas, leads, oportunidades, pedidos, proyectos y facturas en un mismo espacio.

El flujo conecta la venta con el trabajo: al confirmar un pedido, se crea el proyecto y la oportunidad pasa a ganada. Incluye un pipeline visual, tableros de tareas y seguimiento de facturación.

**React · TypeScript · Tailwind CSS · Cloudflare · Drizzle ORM** &nbsp; · &nbsp; [Explorar Siarem →](https://github.com/4pablospena/siarem)
